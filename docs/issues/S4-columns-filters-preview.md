# S4 [의존: S3] 열/필터 구성 + 구조 미리보기

## What to build
S3 뼈대에 이어지는 빌더 하단부 (집계 모드 기준):

1. **차원(행) 선택**: 일자(event_date), 이벤트명, 유입소스(source/medium/campaign),
   선택한 이벤트들의 event_param (파라미터별 칩, 설명 툴팁)
2. **지표(열) 선택**: 이벤트수 / 고유사용자수 / 고유세션수
3. **필터**: [파라미터·기본컬럼] [연산자 =/!=/IN/포함] [값] 행 추가/삭제
4. **구조 미리보기**: 선택 결과의 컬럼 헤더 + 더미값 3행 표. 선택 변경 시 즉시 갱신.
   더미값은 타입에 맞게(날짜/문자/숫자) 생성, 실데이터 아님을 명시하는 캡션 포함.

복수 이벤트 선택 시 파라미터 목록은 합집합, 파라미터가 특정 이벤트에만 있으면 이벤트명 병기.

## Acceptance criteria
- [ ] 차원/지표/필터 변경 시 미리보기 표 즉시 갱신
- [ ] 미리보기에 "구조 확인용 더미값(실데이터 아님)" 캡션 표시
- [ ] 필터 행 추가·삭제 동작
- [ ] 파라미터 칩에 텍소노미 설명 노출(있는 경우)
- [ ] 콘솔 에러 0
