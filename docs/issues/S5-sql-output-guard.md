# S5 [의존: S2, S4] SQL 출력 연결 + 비용 가드 UI

## What to build
S2 엔진과 S4 빌더를 연결해 집계 모드 전체 플로우 완성:

1. **SQL 코드블록**: 선택 확정(생성 버튼) 시 SQL 렌더. 다크 반전 블록(`--code-bg`),
   키워드 하이라이트(단순 정규식 수준), JetBrains Mono
2. **복사 버튼**: 클립보드 복사 + "복사됨" 피드백(2초). "BQ 콘솔에 붙여넣어 실행하세요" 안내 문구
3. **비용 가드**:
   - 기간 미선택 → 생성 버튼 비활성 + 사유 표시
   - 기간 90일 초과 → 경고 배지(아이콘+텍스트, 색상 단독 금지) — 생성은 허용
   - SQL 상단 Assumptions 주석에 스캔량 확인 안내(S2에서 생성)

## Acceptance criteria
- [ ] 이벤트+기간+차원+지표 선택 → 생성 → SQL 표시 → 복사 동작
- [ ] 생성된 SQL을 BQ 콘솔에 붙여넣으면 문법 오류 없이 실행 가능한 형태 (수동 검증 1회)
- [ ] 기간 미선택 시 생성 불가 + 사유 노출
- [ ] 91일 기간 선택 시 경고 배지 노출
- [ ] 콘솔 에러 0, `npm test` 통과
