# S3 [의존: S1] 빌더 UI 뼈대 + 비밀번호 게이트

## What to build
`docs/design/design-system.md`(A안 콘솔 라이트) 토큰을 적용한 단일 페이지 UI 뼈대:

1. **비밀번호 게이트**: 첫 진입 시 비밀번호 입력 화면. 상수(`src/config.ts`의 `ACCESS_KEY = 'gobang'`)와
   비교, 통과 시 sessionStorage 플래그로 세션 유지. (정적 사이트 한계로 완전 보안 아님 — 외부인 차단용)
2. **프로퍼티 탭**: 고방 / U사장님
3. **기간 선택**: 프리셋 칩(최근 7일[기본]/14일/30일) + 직접 입력(date 인풋 2개)
4. **이벤트 선택**: catalog.json 로드 → 검색 인풋 + 이벤트 리스트(한국어 라벨 + 이벤트명 + 설명 + 최근30일 발생량, 퍼널 그룹핑). 복수 선택 가능.

디자인 시스템 준수: 컬러 토큰 CSS 변수화, Pretendard/JetBrains Mono(woff2 셀프호스트 또는 시스템 폴백),
라운딩 6~8px, 이모지 금지(아이콘 필요 시 Lucide SVG 인라인), 포커스 링 유지, 칩 높이 44px.

## Acceptance criteria
- [ ] 비밀번호 불일치 시 에러 메시지, 일치 시 빌더 표시, 새로고침 후에도 세션 유지
- [ ] 프로퍼티 전환 시 이벤트 목록이 해당 프로퍼티 것으로 교체
- [ ] 검색어 입력 시 이벤트명·한국어 라벨 모두 매칭
- [ ] 발생량 표시 (1.2M 형식 축약)
- [ ] 콘솔 에러 0, `npm run build` 성공
