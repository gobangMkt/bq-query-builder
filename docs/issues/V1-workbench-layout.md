# V1 [독립] 워크벤치 스플릿 레이아웃 + 상시 미리보기

## What to build
스펙 §1. 좌(46%) 입력 / 우(54%) sticky 미리보기+SQL 2패널 개편. 헤더에 모드 세그먼트(대화형|셀렉형 — 대화형은 V3 전까지 "준비중" 비활성). 셀렉형 기존 기능 전부 이동, 미리보기는 항상 표시·즉시 갱신.

## Acceptance criteria
- [ ] 우측 패널이 스크롤과 무관하게 고정(sticky), 좌측 변경 즉시 미리보기 갱신
- [ ] 기존 v1 기능(게이트/기간/이벤트/차원/지표/필터/집계·상세/SQL생성·복사·가드) 전부 회귀 없음
- [ ] 1024px 미만 상하 스택
- [ ] E2E 13개 전부 통과(셀렉터 변경 시 테스트 갱신), 콘솔 에러 0
