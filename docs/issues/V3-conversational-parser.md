# V3 [의존: V1, V2] 대화형 파서 + 해석 칩 UI

## What to build
스펙 §3. 규칙 기반 한국어 파서(src/nl/) + 대화형 입력 화면(문장 → 해석 칩(확정/되물음) → 확정 시 셀렉형과 동일 상태로 변환 → 생성). 거절 규칙 5종(순서/기간비교/리텐션/프로퍼티교차/인식실패) 이유+대안 표시. 아이콘은 icon-design 스킬.

## Acceptance criteria
- [ ] 예시 문장 "지난 한 주 동안, 찜 메모를 누른 사람 중 공고완독을 하지 않은 사람들이 발생시킨 조회수를 보고싶어" → 기간7일 + did(찜메모, 되물음 2후보) + notDid(read_complete_notices) + 대상 되물음(조회수 후보) 칩 생성, 확정 후 seg_users 포함 SQL
- [ ] 거절 문장(예: "찜하고 나서 문의한 사람") → 거절 메시지+대안, 생성 차단
- [ ] 파서 vitest 15+ 케이스, 전체 테스트 통과
- [ ] 미확정(노랑) 칩 존재 시 생성 버튼 비활성
