## 레이아웃 개편 (2026-07-03, `sidebar-options.png` B안)
- **3열 워크벤치**: 좌 사이드바(브랜드·프로퍼티·대화형/셀렉형·섹션 내비) · 중앙 스크롤(셀렉형 섹션 카드 또는 대화형) · 우 미리보기+SQL. 각 열 독립 스크롤(height:100vh), 1080px↓ 세로 스택.
- **섹션 내비(스크롤 스파이)**: 기간·이벤트·사람 조건·지표·열·필터. 클릭 시 스크롤, 스크롤 시 현재 섹션 강조(IntersectionObserver, root=중앙).
- **기간 컨트롤**: 프리셋 pill(최근 7/14/30일) + "직접 선택" — 직접일 때만 날짜 범위 입력이 펼쳐짐(불필요 노출 제거). 선택 pill은 primary 채움.
- **이벤트 목록 간소화**: 행 = 라벨+이벤트명+발생량(한 줄). 긴 설명은 인라인 제거.
- **이벤트 사전**: 각 행 옆 ⓘ(`<details>` 팝오버) → 설명 + 파라미터 표(파라미터·타입·설명). 전역/공통 파라미터는 '공통' 태그. 상속 결과(예: inquiry가 branch_id 보유)가 실측 그대로 반영됨.
- **파라미터 모델**: 전역/상위컬럼 상시 + 선택 이벤트 union(상속 포함). 일부 이벤트에만 있는 파라미터는 "○○에만 있음 — 나머지 행 NULL" 툴팁. 세션 스티칭 없음.
- 집계/상세(Wide) 토글은 "지표·열" 섹션 헤더에 배치. 상세 모드 유지.

## 컨셉
BQ 콘솔과 나란히 두고 쓰는 도구 — 같은 라이트+블루 시각 문법으로 연속성 유지.
SQL 출력 블록만 다크 반전 → "복사해갈 코드" 영역임을 시각적으로 구분.

## 타이포그래피
- UI: **Pretendard** (로컬 폰트 스택 fallback: -apple-system, 'Malgun Gothic')
- 코드·컬럼명·더미값: **JetBrains Mono** (fallback: Consolas, monospace)
- 스케일: 13(라벨) / 15(본문·칩) / 17(섹션제목) / 22(페이지제목), 본문 line-height 1.5+
- 숫자 컬럼은 tabular figures

## 형태 규칙
- 라운딩: 6px(칩·버튼·코드블록), 8px(카드). 그 이상 금지
- 그림자: 카드 1단계(`0 2px 12px rgba(0,0,0,.12)`)만. 남발 금지
- 선택 상태: `--primary-soft` 배경 + `--primary` 테두리+텍스트 (색상+테두리+굵기 3중 표시)
- 아이콘: Lucide SVG만, 이모지 금지, stroke 1.5px 통일
- 안티클리셰 준수: border-left 액센트 도배 금지, pill 남발 금지, 그라데이션 금지

## 접근성
- 본문 대비 4.5:1 이상 (`#1C2733` on `#FFF` = 14.5:1, `#5F6A79` on `#FFF` = 5.6:1 ✓)
- 터치 타깃 44px 이상(칩 높이 포함), 포커스 링 유지
- 경고는 색+아이콘+텍스트 동반
