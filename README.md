# BQ 쿼리 빌더

## 개요
SQL/BigQuery를 모르는 구성원(UX팀 등)이 **BigQuery SQL 텍스트**를 만드는 정적 웹 도구.
도구는 SQL 생성까지만 하고, 실행은 항상 사람이 BQ 콘솔에서 직접 한다.
셀렉형(클릭 조립)은 서버·LLM·API·자격증명 0. 대화형(자연어)은 GAS 프록시를 거쳐 Gemini로 SQL을 생성한다 — 이 경우도 **프록시가 BigQuery를 직접 실행하지 않으며**, SQL 텍스트만 돌려준다.

## 코어
- **레이아웃**: 상단 바(브랜드 + 이벤트 사전) · 좌 작성(대화형/셀렉형 탭 → 그 아래 찾을 데이터 고방/U사장님 → 입력) · 우 큰 미리보기+SQL. 좌/우 사이 **드래그 리사이저**로 폭 조절(localStorage 기억, 데스크톱 전용). 디자인: 뉴트럴 미니멀(개발자 도구 톤, pill 남발·과한 라운딩 배제).
- **셀렉형 = 문장 채우기**: "**[고방] 데이터에서 · [기간] 동안 · [이벤트]를 · [조건]인 것만 골라 · [행]별로 묶어 · [값]을 본다** (단, [사람 조건]만)". 좌측 라벨이 이 조사형 문장 그대로이고, **우측 구조 미리보기 위에 현재 선택으로 조립된 완성 문장이 항상 표시**된다(미선택 부분은 회색). 문장 순서가 곧 SQL(FROM→WHERE→SELECT→GROUP BY→JOIN). 이벤트를 고르기 전엔 조건·행·값을 감춰 초기 화면을 단순하게 유지(progressive).
- **이벤트는 팝업으로만**: 처음부터 전체 목록을 펼치지 않음. "+이벤트" 또는 상단 "이벤트 사전" → 검색 모달에서 고름.
- **대화형(v6)**: 자연어 질문 → GAS 웹앱 프록시가 Gemini 2.5 Flash로 **BigQuery SQL을 직접 생성**(규칙파서로 불가했던 CTR·비율 등도 처리). 프록시가 실측 카탈로그(선택 프로퍼티 1개, 트림)를 grounding으로 주입해 이벤트명·파라미터 환각을 막고, 출력가드(읽기전용·`_TABLE_SUFFIX`·허용 데이터셋·카탈로그 존재 여부)+자가수정 1회로 검증한다. 프록시 실패/미배포 시 기존 규칙 파서 해석 칩으로 자동 폴백. 두 모드는 상태 공유. `@` 입력 시 **이벤트 자동완성 드롭다운**(↑↓·Enter·Esc). **구조 확인 단계**: [해석하기] → SQL을 바로 노출하지 않고 해석 문장+결과 컬럼(최종 SELECT에서 추출, `src/nl/sql-columns.ts`)을 우측 구조 미리보기에 먼저 보여줌 → [맞아요, 이대로] 클릭 시 받아둔 SQL을 **우측 SQL 패널**에 노출(재호출 없음, 추가 비용 0). SQL 표시는 항상 우측 한 곳 — 대화형 모드에선 셀렉형용 [SQL 생성] 버튼이 숨는다.
- **AI 생성 SQL 서식**: 대화형이 만드는 SQL은 압축 한 줄이 아니라 **섹션 주석(`/* ===== … ===== */`)·2칸 들여쓰기·절별 줄바꿈**으로 사람이 바로 읽고 편집하도록 출력한다(프롬프트에 서식 규칙·예시를 강제). 각 컬럼·집계 표현식에 무엇을 구하는지 한국어 주석을 단다.
- **비용 하드캡(대화형 AI 호출)**: 프록시가 Gemini 실비를 월별 누적, **₩1,500 도달 시 호출 자체를 거부**. 동일 질문 6시간 캐시로 재호출 0. 셀렉형은 LLM을 아예 타지 않아 비용 무관. **대화형 패널 상단에 이번 달 사용액/한도(₩1,500) 진행바를 상시 표시**(초기 GET 조회 + 매 응답 갱신, 70%/90%에서 색 경고).
- **기간**: 시작/끝 날짜 입력 **상시 노출** + 최근 7/30/90 세그먼트 퀵셋(누르면 범위 자동 채움, 날짜 직접 수정 시 프리셋 해제).
- **이벤트 사전(모달)**: 좌 리스트(클릭=선택 토글, 체크 표시) · 우 **상세 pane**(호버/클릭 시 설명 + 추출 가능한 파라미터 표[타입·설명, 전역은 '공통'], 추가/빼기 버튼). 어느 파라미터가 어느 이벤트에 있는지(상속 결과 포함) 확인용.
- **사람 조건(세그먼트)**: 조회 기간 내에 특정 이벤트를 "했다/안 했다"로 유저를 거른다 → `seg_users` CTE(`HAVING COUNTIF`). "A 한 사람 중 B 안 한 사람" 류를 지원.
- **파라미터 한계 안내**: 파라미터는 선택 이벤트가 실제 가진 것(union, dataLayer 상속 반영)만 노출. 일부 이벤트에만 있으면 "○○에만 있음 — 나머지 행 NULL" 툴팁. 이벤트 간 값 스티칭(예: ad_banner_view에서 branch_id)은 데이터 구조상 불가하며 시도하지 않음.
- **원리**: 실측 인벤토리(`data/inventory-*.json`, 사용자가 BQ에서 30일 검증쿼리 실행) + 노션 텍소노미(`data/taxonomy-*.json`)를 빌드 시 병합해 `src/data/catalog.json` 생성 → 규칙 템플릿이 노션 "[지침] SQL 작성" 서식대로 SQL 생성. 대화형 유의어는 `src/nl/dictionary.ts`.
- **스택**: Vite + vanilla TypeScript (런타임 의존성 0), vitest 93 + Python Playwright E2E 32(프록시는 네트워크 모킹 — 실 Gemini 호출 0)
- **비용 가드**: 기간 미선택 시 생성 불가(`_TABLE_SUFFIX` 항상 포함), 90일 초과 경고, 상세 모드 기본 LIMIT 1000
- **대상 데이터**: `gobang-bigquery.analytics_274122040`(고방 raw) / `analytics_279311003`(U사장님 raw)
- **접근**: 진입 시 비밀번호 게이트 (`src/config.ts`의 `ACCESS_KEY` — 클라이언트 검증이라 완전 보안 아님, 외부인 차단용)

## 대화형이 지원하는/안 하는 것
| 지원 | 안 됨(이유 + 대안 안내) |
|---|---|
| 기간(지난 한 주/한 달/N일) | 순서 조건(A 하고 나서 B) → 발생 여부로 바꾸기 |
| 사람 조건 여러 개(했다/안 했다) | 기간 비교/증감 → 기간별로 각각 생성 |
| 대상 이벤트 + 지표(이벤트수/사용자수/세션수) | 리텐션·코호트 → 미지원 |
| 애매하면 되물음 칩으로 후보 선택 | 프로퍼티 교차(고방+U사장님) → 하나씩 |

## 실행·배포
- 로컬: `npm install` → `npm run dev` (포트 3095) 또는 루트의 `시작 3095.bat`
- 테스트: `npm test` / E2E: 서버 띄운 뒤 `python tests/e2e.py`
- 빌드: `npm run build` (build:catalog → tsc → vite build → dist/)
- 배포: master push 시 GitHub Actions가 Pages로 자동 배포 (`.github/workflows/deploy.yml`)

### 대화형 AI 프록시 (gas-proxy/)
- GAS 웹앱(Apps Script, 별도 배포). 시크릿(`GEMINI_API_KEY`, `ACCESS_KEY`)은 프록시의 Script Properties에만 저장 — repo에 없음.
- 클라이언트는 `src/config.ts`의 `PROXY_URL`(exec URL)로 이 프록시를 호출. 배포·재배포 절차는 `gas-proxy/README.md`.

### 카탈로그 갱신 (GTM 이벤트 추가/변경 시)
1. `docs/verify-query.sql`을 BQ 콘솔에서 실행 (고방·U사장님 각 1회, 데이터셋 ID만 교체)
2. 결과를 JSON으로 저장해 `data/inventory-*.json` 교체
3. 텍소노미 변경분은 `data/taxonomy-*.json`에 반영
4. `npm run build:catalog` → 커밋·push → 자동 재배포
